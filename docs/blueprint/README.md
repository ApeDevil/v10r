## Features

| File | Main Topics |
|------|-------------|
| **[auth.md](./auth.md)** | • **Passwordless**: magic link + OTP (no passwords)<br>• Better Auth setup: `$lib/server/auth/index.ts` with Drizzle adapter<br>• Client setup: `$lib/auth-client.ts` for browser use<br>• Authentication flows: magic link, OTP code, OAuth (GitHub, Google)<br>• Session management: database-backed, cookie-based, 30-day default<br>• Route protection: per-route guards with `requireAuth()` helper<br>• OAuth: `signIn.social()`, redirect handling, profile mapping<br>• Email sending: magic link + OTP in same email, user chooses method<br>• Hooks integration: populate `event.locals.user`, `event.locals.session`, `event.locals.grants`<br>• **Capability grants**: `auth.grant` + `auth.grant_request` tables; `guardApiBlogAuthor` guards; `grants` populated per-request in hooks; admin endpoints at `/api/admin/grant-requests` + `/api/admin/users/[id]/grants`<br>• **Passkeys & step-up TOTP**: passkey = phishing-resistant first factor; TOTP = step-up only (no login challenge — twoFactor gates credential sign-in, which passwordless lacks); `before`/`after` hook chokepoint (audit + sibling-revoke + email + step-up stamp); Redis `stepup:<userId>` freshness gate (fail-closed); `/account/security` enrollment; StepUpDialog; passkeys excluded on Vercel previews<br>• **Rate limiting**: per-email limiter on magic-link/OTP send — see [abuse/rate-limits.md](./abuse/rate-limits.md)<br>• CSRF protection: enabled by default, `csrfProtection` option<br>• Security: rate limits by endpoint, audit logging, 10-min token expiry<br>• **Namespace gotcha**: `/api/auth/*` owned by Better Auth's catch-all — custom routes must live outside this prefix<br>• **Admin gate**: `requireAdmin`/`guardApiAdmin` return 404, never 403 — denied is indistinguishable from absent<br>• **Audit log**: `admin.audit_log` has no FK on `actor_id` (survives actor deletion) + denormalized `actor_email` (reads without a join) |

| **[state.md](./state.md)** | • Svelte 5 runes: `$state`, `$derived`, `$effect`, `$props`, `$bindable`<br>• `$state`: reactive variables, deep proxy for objects/arrays<br>• `$state.raw`: opt out of proxy, only reassignment triggers updates<br>• `$state.snapshot`: plain object copy for API calls, cloning<br>• `$derived`: computed values (memoized, lazy), use 90% of the time<br>• `$derived.by`: multi-statement computations, must be pure<br>• `$effect`: side effects after DOM update, cleanup pattern<br>• `$effect.pre`: before DOM update (scroll position capture)<br>• Module state: `.svelte.ts` files, factory pattern for instances<br>• Context API: SSR-safe shared state, `setContext()` / `getContext()`<br>• **Better Auth session state**: use `event.locals` (SSR-safe), not module-level `useSession()`<br>• Reactive built-ins: `SvelteMap`, `SvelteSet`, `SvelteDate`, `SvelteURL`<br>• UI state: sidebar (open/pinned), theme (light/dark/system), localStorage sync<br>• Anti-patterns: modify state in `$derived`, use `$effect` for computation, forget cleanup |
| **[i18n.md](./i18n.md)** | • Library: Paraglide JS v2 (compile-time messages, tree-shakeable, type-safe)<br>• Routing: `[[locale=locale]]` optional catch-all (`/`, `/de`, `/de/about`); default `en` unprefixed<br>• Param matcher: `src/params/locale.ts` validates the locale segment (en/de/ru)<br>• Locale resolution: **no `reroute` hook** — locale lives in the route tree; `/en/*` 308-redirects to canonical unprefixed<br>• Middleware: `i18n` handle (wraps `paraglideMiddleware`) stamps `event.locals.locale`, persists `PARAGLIDE_LOCALE` cookie, injects `%lang%`<br>• Messages: `messages/{locale}.json` (ICU MessageFormat) compiled to `$lib/paraglide/messages`; used as `m.greeting({ name })`<br>• Language switcher: client `goto()` + cookie write, `{#key}` re-render (messages aren't reactive)<br>• Date/number formatting: native `Intl` API, locale passed explicitly (SSR/CSR parity)<br>• SEO: `hreflang` alternates, localized `sitemap.xml`, per-locale self-canonical<br>• DB content: `<name>` column + `<name>_i18n` JSONB sidecar, resolved via `tc(source, i18n, locale)`<br>• Plural correctness: `plurals.test.ts` enforces CLDR categories (catches `one`/`other`-only Russian) |
