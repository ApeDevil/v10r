# Testing

Testing strategy and infrastructure for the Velociraptor project. Start with **strategy.md** — it states what earns a test and how the suite is laid out. Covers the two-tool strategy (Vitest 4.x + Claude Chrome extension), AI agent testing loops, database isolation with PGlite, and Claude Code hooks.
