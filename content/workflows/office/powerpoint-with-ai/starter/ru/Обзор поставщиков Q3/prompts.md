# Промпты для обзора поставщиков

По одному промпту, в этом порядке. Подставьте сегодняшнюю дату.

## Найти ключевую мысль (если её ещё нет)
Прочитай отчёт и предложи три варианта ключевой мысли для этой аудитории, каждый одним предложением.

## Сначала сюжет
Прочитай README.md и файлы в input/. Напиши output/<дата>/storyline.md: для каждого слайда
заголовок одним полным предложением, два-три поясняющих пункта и источник каждого числа (файл,
лист и ячейка или страница). Затем перечисли всё из источников, что не вошло в сюжет, и почему.
Слайды пока не делай.

## Слайды по сюжету
Собери презентацию по output/<дата>/storyline.md на шаблоне из template/. Заголовки сохрани слово
в слово. Диаграммы берутся из input/q3-figures.xlsx.

## Заметки докладчика
Для каждого слайда напиши заметки докладчика из трёх-пяти предложений: что сказать и какая
подробность не поместилась на слайд. Используй только факты из источников.

## Проверка чисел
Перечисли каждое число в презентации со слайдом, значением и ячейкой источника; отметь те, которые
не удаётся проследить. Сохрани это как output/<дата>/numbers-check.md.

## Проверка аудиторией
Какие три вопроса зададут руководители закупок после этого? Есть ли ответ на каждый?

## Фиксация
Добавь сегодняшние решения в раздел «Решения» в README.md.
